# 💳 Credit Card Financial Dashboard

## 📊 End-to-End Data Analytics Project

This project is an end-to-end Data Analytics project focused on analyzing credit card customer and transaction data using **SQL and Power BI**.

The project transforms raw customer and transaction data into interactive dashboards to monitor revenue, transaction performance, customer demographics, card categories, expenditure patterns, and key financial KPIs.

## 🎯 Project Objective

The objective of this project is to build an interactive Credit Card Financial Dashboard that enables analysis of key financial performance metrics and customer behavior.

The dashboard provides insights into:

- Revenue
- Transaction Amount
- Transaction Count
- Interest Earned
- Annual Fees
- Customer Income
- Customer Demographics
- Card Category
- Expenditure Type
- Customer Job
- Geographic Distribution
- Weekly and Quarterly Trends
